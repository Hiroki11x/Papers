# 論文ノート全体カタログ（全572件）

GitHub Issues に記録された論文ノート全件を、重点3分野とその他に分類し、採択先と公開時期を整理したカタログです。各分野の詳細な解説は個別ドキュメントを参照してください。

- 採択先の「根拠」は、issue記載（ノート本文やリンク）、arXivコメント（arXiv API の comment / journal_ref）、既知情報（論文の既知の採択情報）、不明（採択の根拠なし＝プレプリント扱い）のいずれかです。
- 公開年月は arXiv の初回投稿日（なければ採択年など）です。issue 作成日（読んだ日）とは異なります。
- 1本の論文が複数分野にまたがる場合、各分野に重複して数えています。
